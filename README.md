# 🤖 Robotic Arm Project

## Overview

This project is a robotic arm controlled using Arduino and Python. The system can move the robotic arm through commands sent from a computer to the Arduino board.

## Features

* Robotic arm movement control
* Arduino and Python communication
* Servo motor based operation
* Real-time control from computer

## Components Used

* Arduino Uno
* Servo Motors
* Robotic Arm Chassis
* Jumper Wires
* Power Supply

## Software Used

* Python
* Arduino IDE
* PySerial

## How It Works

1. Python sends commands from the computer.
2. Arduino receives the commands through serial communication.
3. Arduino controls the servo motors.
4. The robotic arm moves according to the received command.
